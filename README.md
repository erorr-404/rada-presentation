# Сайт Ради Президента 4 ліцею

## Інструкція для підтримки сайту для команди Ради Президента

### Структура

У коді цього проєкту є багато різних папок з кодом. Проте для підтримки сайту потрібні лише кілька з них.

* #### [`./`](./) (кореневий каталог)

Тут знаходиться всі сторінки сайту, JavaScript скрипти, трошки стилів та додаткові, нецікаві вам файли (CNAME, .gitignore, package-lock.json, package.json). Аби підтримувати сайт вам не треба буде чіпати їх.

* #### [`./assets`](./assets) папка з ілюстраціями

У цьому каталозі знаходяться фото для галереї [`/gallery`](./assets/gallery), лого сайту [`/icons`](./assets/icons) у різних форматах, фотографії учасників ради [`/members`](./assets/members), фони і додаткові фотографії.

* #### [`./data`](./data) папка з даними

У цій папці зберігаються всі дані про свята [`news.json`](./data/news.json) та учасників [`members.json`](./data/members.json).

* ### Інші папки

У папках `./node_modules` та `./scss` зберігаються файли [Bootstrap](https://getbootstrap.com/) та [JQuerry](https://jquery.com/). Їх чіпати не потрібно.

### Зміна контенту

#### Зміна складу Ради Президента

* Щоб додати нову людину на сайт, потрібно виконати такі дії:

    1. Відкрити файл [`members.json`](./data/members.json)
    2. Після `[` або будь-якого іншого учасника вставити наступний код:

        ```json
        {  
            "firstName":"ім'я",
            "secondName":"прізвище",
            "position":"посада",
            "description":"невелики опис, можна з емодзі 🧑‍💻",
            "image":"./assets/members/фото_учасника_англійською.jpg",
            "id":"унікальне_кодове_ім'я_англійською",
        },
        ```

    3. Додати фото учасника у каталог [`./assets/members`](./assets/members), а його назву та тип записати у `фото_учасника_англійською.jpg`

    4. Зберегти файл та перевірити чи все працює.

* Для того, щоб прибрати когось із сайту потрібно:

    1. Відкрити файл [`members.json`](./data/members.json)
    2. Знайти учасника
    3. Прибрати його фото у папці [`./assets/members`](./assets/members)
    4. Прибрати інформацію про нього
    5. Зберегти та перевірити
